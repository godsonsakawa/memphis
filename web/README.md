# 🚀 Next.js Project

A modern web application built with [Next.js](https://nextjs.org), bootstrapped using [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## 🛠️ Getting Started

### Prerequisites
- Node.js (Latest LTS version recommended)
- npm, yarn, pnpm, or bun

### Installation & Development

1. Clone the repository
2. Install dependencies:
```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

3. Start the development server:
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

The page auto-updates as you edit files in the `app` directory.

## 🎨 Features

- ⚡️ Next.js 13+ with App Router
- 🎯 TypeScript support
- 🎨 [Geist](https://vercel.com/font) font optimization using `next/font`
